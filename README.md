# Préstamos PWA

Gestión de préstamos personales, 100% local (IndexedDB), instalable y offline.

```bash
npm install
npm run dev
```

`npm test` corre los tests del motor de intereses. `npm run build` genera `dist/` listo
para cualquier hosting estático. El contexto del proyecto y las reglas de negocio están
en [CLAUDE.md](./CLAUDE.md).
